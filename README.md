# OB Sommelier

Find where to buy a wine near you in Aruba, at the best price, and what to eat with it.
Static web app (no build step) on GitHub Pages; data in Supabase.

- `index.html` shopper app · `vendor.html` store portal · `contribute.html` shelf-photo contributors · `privacy.html` privacy and terms
- `config.js` holds the public Supabase URL and anon key (public by design; Row Level Security protects the data)
